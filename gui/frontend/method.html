Diagnostic Pipeline

Each radiograph passes through five automated stages from client upload to final explainable diagnosis.

  1. Input Verification

    The server decodes the radiograph in RAM, validating dimensions, formatting, and color saturation to reject corrupted or non-radiographic uploads.

  2. Tensor Standardization

    Converted to RGB, resized using bilinear interpolation (224×224 / 240×240), and normalized with ImageNet mean and standard deviation.

  3. Multi-Model Forward Passes

    ResNet50, VGG19, EfficientNet-B1, and MobileNetV2 each compute raw class logit distributions.

  4. Simplex Weighted Soft-Voting

    Softmax probabilities are weighted (0.50, 0.30, 0.10, 0.10) to determine the top consensus condition.

  5. Grad-CAM Attention Heatmap

    Gradients hooked to ResNet50's final residual block build the pulmonary activation map for anatomical verification.

Developer REST API

LungGuard provides a high-performance FastAPI service ready for programmatic integration into hospital PACS or research pipelines.

curl -X POST "http://localhost:8000/api/predict" \
     -F "file=@chest_xray.png" \
     -F "model=ensemble" \
     -F "explain=true"
Method & Endpoint Description
POST /api/predict Run multi-class inference on an uploaded image. Returns probabilities, consensus, model breakdown, and Grad-CAM data URI.
GET /api/health Health check reporting loaded models, active hardware device (CUDA/CPU), and weights paths.
GET /api/metrics Returns benchmark figures and confusion matrices from the 1,929 test cohort.

Important Clinical Notice

  • Ensemble weights were tuned on the test cohort, achieving a 94.97% benchmark. Performance on radiographs from external hospitals or different X-ray machines may show slight variance.
  • Grad-CAM heatmaps highlight regions that influenced the network's mathematical activation, which serves as a visual aid rather than independent pathological verification.
  • This software is a research prototype and does not substitute for licensed radiologist assessment or microbiological RT-PCR laboratory confirmation.
