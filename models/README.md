# Model Weights Directory

Place the four trained PyTorch model checkpoints (`.pth`) in this directory:

- `resnet50.pth` (~94.4 MB)
- `vgg19.pth` (~558.3 MB)
- `efficientnet_b1.pth` (~26.5 MB)
- `mobilenet_v2.pth` (~9.2 MB)

### 📥 Download Link
Download all four `.pth` model files from the official Google Drive repository:
👉 **[Google Drive Model Weights](https://drive.google.com/drive/folders/1GwJ8Yt1tVA9e8vom0FzrbroRXBqL7FDt?usp=sharing)**

Once downloaded, place all 4 files directly into this `models/` folder. Both the CLI and GUI versions of LungGuard will automatically detect and load them.
